# QiLoom

Free web tools for Gregorian and Chinese lunar dates, birthdays, and family occasions.

Website: [https://qiloom.com](https://qiloom.com)

## Problem

Everyday calendar questions often require switching between conversion websites,
age calculators, festival references, and planning notes.

QiLoom brings these related tasks into one web destination.

## Features

- Gregorian and Chinese lunar calendar conversion
- Lunar birthday lookup
- Chinese zodiac lookup
- Completed-age calculation
- Date interval calculation
- Baby full-month and hundred-day calculations
- Calendar and traditional festival references
- Engagement preparation checklist

## Tech Stack

QiLoom is available as a web application.

The production framework, calendar dependencies, hosting setup, and build
instructions are not documented in this README. No source-code availability
or open-source license is implied by this product overview.

## How to use

1. Open https://qiloom.com.
2. Choose the relevant calendar or planning tool.
3. Enter the requested date information.
4. Review the result and any applicable calendar or counting conventions.
5. Confirm family-specific customs before planning an important celebration.

## Calendar considerations

Leap months, zodiac year boundaries, and inclusive day counting can affect
how a date-related question should be interpreted.

When reporting an issue, include the input date, selected tool, expected result,
and the reference or convention used.
